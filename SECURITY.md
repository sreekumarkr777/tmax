# Security

Tmax runs Claude Code in terminals on your own machine. Claude Code reports its activity to Tmax through a hook server that listens only on `127.0.0.1` and requires a random per-launch token. Tmax has no servers, accounts or analytics.

If you find a security problem, please don't open a public issue. Report it privately through GitHub's **Report a vulnerability** button on the repository's Security tab. I'll reply as soon as I can.
